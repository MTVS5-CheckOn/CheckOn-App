# 학생 앱 UI·상태 구현 체크리스트

Figma `Student / Main Screens`와 인증 화면을 Next.js 구현 명세로 사용한다. API 연결 전에는 mock gateway와 Zustand persist store를 사용하고, 서버 데이터는 추후 TanStack Query gateway만 교체한다.

- [x] 로고 로딩: 0→100% 진행률, 완료 후 자동 이동
- [x] 온보딩: 3단계 이동, 단계 선택, 이전/다음, 현재 단계 유지
- [x] 로그인: 입력 검증, 비밀번호 표시, 활성/비활성 계정 분기
- [x] 회원가입 약관: 필수/선택/전체 선택, 단계 이탈 후 선택 유지
